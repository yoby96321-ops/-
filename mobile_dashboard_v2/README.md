# 00403A 線上版 v2（獨立重建）

本資料夾與 `mobile_dashboard` v1 分離。v1 快照位於同層 `mobile_dashboard_v1_snapshot_時間戳`，原線上站及發布器不改動。

## v2 原則
- 目標是靜態手機／平板／桌面網站，先建乾淨介面與資料格式，再決定免費資料供應方式。
- 歷史回放按交易日期前進：每個預測只能使用當時已知資料；收盤後才記錄實際答案。
- 資料不足時允許產生探索性估計，但標示樣本數和不確定性；不得將未來資料用於當日訓練或參數挑選。
- 不把相似日曲線或技術指標包裝成已驗證的機器學習準確率。
- 優先使用官方免費日行情；盤中資料來源與歷史覆蓋範圍需明確標示。
- 新版獨立發布，不覆蓋 v1 GitHub Pages，待驗收後再切換。

## 目錄
- `site/index.html`：v2 響應式網站
- `data/`：v2 資料 schema 與模擬／發布資料
- `README.md`：版本及資料流程
